# Detector geometry slides

## Tool User Guide

`tool_user_guide_slides.pdf` is the user-facing presentation: what the tool
does, the six default FT-with-hole/UP setups, both magnet polarities, TV
counting, MT cuts, and the precise output-property contract. The editable
LaTeX source is `tool_user_guide_slides.tex`.

`tool_output_schema.json` is generated by executing the example against the
bundled field map. It lists every default column, its dtype and values for
two example tracks: 41 properties for each of 12 geometry/polarity predictions.

Regenerate the schema, example tables and user-guide PDF from the repo root:

```bash
PYTHONPATH=src python examples/create_tool_user_guide_slides.py
```

The existing `acceptance_study_summary.pdf` is the complementary study deck,
including the field-propagated count toy, TV efficiencies and timing emulation.

## Geometry Derivation

`detector_geometry_slides.tex` is the editable Beamer source for the slide
summary. `assets/` contains the generated geometry summary and six-configuration
comparison used as figure sources in the deck.
The UP variant slide labels each border choice and lists the common central
hole dimensions measured from the saved UP polygons.

Build from this directory with:

```bash
pdflatex -halt-on-error -interaction=nonstopmode \
  -output-directory=../../output/pdf detector_geometry_slides.tex
cp ../../output/pdf/detector_geometry_slides.pdf .
```

The reusable source of truth for selected plane names, XY shapes, and exact
global z positions remains in `detector_setups/catalog.json` and each setup's
`layout.csv` / `shapes/` payload.
